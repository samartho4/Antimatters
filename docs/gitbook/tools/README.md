# Tools

Antimatters empowers its agents with a specialized toolkit, categorized by function:

1.  **[The Physics Engine](custom-mcp.md)**: Tools that simulate physical reality.
    *   *AutoDock Vina, RDKit, PED.*

2.  **[The External Brain](context-resources.md)**: Tools that access human knowledge.
    *   *BioContext (PubMed/EuropePMC).*

3.  **[The Databases](mcp-databases.md)**: Tools that store and retrieve structured data.
    *   *ChEMBL, Neo4j, SQLite.*

We use the **Model Context Protocol (MCP)** to standardize these diverse tools (Python, Node.js, binaries) into a single, agent-callable interface.
